## 🌱 О проекте

**Plantique** — это современный интернет-магазин комнатных растений с полным циклом покупок. Проект включает в себя:

- 🏠 **Главную страницу** с каталогом растений и фильтрами
- ❤️ **Избранное** для сохранения понравившихся товаров
- 🛒 **Корзину** с управлением количеством товаров
- 👤 **Систему авторизации** с регистрацией и личным кабинетом
- 📦 **Оформление заказа** в 4 простых шага
- 📱 **Полностью адаптивный дизайн** для всех устройств

Проект работает без серверной части — все данные сохраняются в `localStorage` браузера.

## ✨ Возможности

### 🛍️ Покупки

- **Каталог растений** с красивыми карточками товаров
- **Фильтрация** по категориям (Outdoor, Indoor, Flower Pots, Potted Plants)
- **Добавление в корзину** одним кликом
- **Управление корзиной** — изменение количества, удаление товаров
- **Избранное** — сохранение понравившихся растений

### 👤 Авторизация

- **Регистрация** нового пользователя
- **Вход** по email и паролю
- **Личный кабинет** с редактированием профиля
- **История заказов** — все заказы пользователя
- **Смена пароля** в настройках
- **Автоматический вход** при повторном посещении

### 📦 Оформление заказа

Пошаговый процесс оформления:

1. **Контактные данные** — имя, email, телефон
2. **Адрес доставки** — полный адрес с комментарием
3. **Способ оплаты** — карта, наличные или онлайн-оплата
4. **Подтверждение** — обзор всего заказа

### 🎨 Дизайн

- ✨ **Современный UI** с градиентами и тенями
- 🎭 **Плавные анимации** при скролле и взаимодействии
- 📱 **Полная адаптивность** — от мобильных до десктопов
- 🌈 **Красивые модальные окна** с эффектом размытия
- 🎯 **Индикаторы шагов** при оформлении заказа
- 🔔 **Уведомления** о действиях пользователя

## 🚀 Установка и запуск

### Требования

- Современный браузер (Chrome, Firefox, Safari, Edge)
- Локальный сервер (опционально, но рекомендуется)

### Способ 1: Простой запуск

Просто откройте `index.html` в браузере:

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

### Способ 2: Локальный сервер (рекомендуется)

**Python 3:**
```bash
cd growth
python -m http.server 8000
```

**Node.js (http-server):**
```bash
npx http-server -p 8000
```

**VS Code Live Server:**
1. Установите расширение "Live Server"
2. Правый клик на `index.html` → "Open with Live Server"

Затем откройте: `http://localhost:8000`
